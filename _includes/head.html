{%- comment -%} ?v= is the build time. GitHub Pages serves everything with cache-control: max-age=600, so without this a returning visitor can get new HTML alongside up-to-ten-minute-old CSS. A new build changes the URL, so the browser cannot serve a stale copy. Vendor libraries are deliberately left un-busted: they never change, and busting them would re-download jQuery and Bootstrap on every deploy. {%- endcomment -%}
